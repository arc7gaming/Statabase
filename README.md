# Statabase

## Welcome to the statabase interactive platform!

### How to run:

Run the file "main.py" in order to access all the features of the program.

### The features:

The user has the option to add new players into the database, remove players from the database, add new games for the player or remove games from the player. This program will consider a large range of statistical categories used in basketball. After the user inputs the required data, the program will present the data in a nicely formatted table and will also calculate the averages of the data inputted.

### Why use this program?

This program provides more efficient stat tracking than any spreadsheet application would.
